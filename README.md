# wctool
**wctool** - a copy of GNU WC

## Decscription
This s a tool, that faster than GNU WC.

## Features
- Very fast work
- Quick start

### Build
Needed:
- C Compiler
- CMake 3.10 and greater
- GNU Make

```bash
cmake -B build
cd build/
make
```
